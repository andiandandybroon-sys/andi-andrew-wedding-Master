# Andi & Andrew - Edinburgh Celebration

A responsive static wedding website for GitHub Pages.

## Preview locally

Open `index.html` in a browser. The homepage, video, images, countdown, calendar download and RSVP preview work without a server.

## GitHub Pages upload

1. Open the repository in GitHub.
2. Upload the contents of this folder, not the folder itself.
3. Keep the `assets/images` and `assets/video` folders unchanged.
4. Commit the files to the `main` branch.
5. Open Settings > Pages.
6. Select Deploy from a branch, `main`, and `/ (root)`.

## RSVP status

The RSVP page is currently a front-end preview. It stores a reply only in the guest's browser using local storage. It does not send data to Andi and Andrew yet.

Before invitations are issued, connect the form to a real service such as Formspree, Netlify Forms, Google Apps Script or Supabase.
